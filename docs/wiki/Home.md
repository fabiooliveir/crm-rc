# CRM-RC Wiki - Documentação Oficial 💼📖

Bem-vindo à **Wiki Oficial do CRM-RC** (CRM para Representantes Comerciais).

O **CRM-RC** é um sistema desenvolvido para empoderar o representante comercial independente, garantindo que sua carteira de clientes, histórico de negociações, tabelas de preços e extratos de comissão pertençam exclusivamente a ele, garantindo total soberania de dados caso troque de empresa representada.
